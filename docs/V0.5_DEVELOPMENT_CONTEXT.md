# MediPrompt v0.5 Development Context — Grounded Refinement

Status: implemented on `feature/v0.5-gap-score-and-semantic` in PR #20, reviewed against the
v0.5 exit gate on 2026-09-01. Base: `develop` after v0.4.

This file is the executable v0.5 contract. It records the final reviewed behavior, including why
the product says **Refinement Delta**, not “Gap Score”.

## 1. Outcome

v0.5 closes one practice loop without turning a medical-content matcher into a grade:

- The learner can retry the exact same topic and practice conditions.
- Attempt two and later show **Refinement Delta** only when the complete attempt and numeric-scoring
  identities match.
- The delta includes newly covered and no-longer-detected concepts plus a bounded, session-local
  attempt trace.
- Optional MiniLM meaning matching runs locally. It compares bounded transcript segments with
  rubric labels/phrases and shows **possibly present — not counted** evidence.
- Until an educator-labelled calibration set exists, semantic evidence cannot silently promote a
  concept into numeric coverage. Deterministic lexical coverage remains the numeric baseline.

“Gap Score” stays reserved for a future construct with an independent knowledge baseline or
educator judgement. Refinement Delta measures only change in detected rubric coverage.

## 2. Explicit exclusions

- Medical correctness, confidence, emotion, accent, competence, or long-term-learning inference.
- Persistent history, accounts, backend storage, analytics, or transcript upload.
- Viva follow-ups and spaced resurfacing (v0.6).
- Semantic-to-numeric promotion before educator-labelled calibration.
- PDF authoring/content compiler (v0.7) and connected provider coaching (v1.1+).

## 3. Retry and attempt history

`REVIEW → START_SECOND_ATTEMPT → TOPIC_READY` reuses the same immutable `TopicSnapshot` and creates
a fresh attempt ID. The completed attempt is appended to `AttemptDraft.history`; at most 19 prior
entries are retained, so transcripts cannot grow memory without bound. The visible attempt number
continues increasing even when older entries age out.

Starting a retry emits `REVOKE_RECORDING` for the completed attempt before focusing the topic. This
prevents attempt two from displaying or retaining attempt one's playback, PCM, or object URL.

Each history entry records only session-local data:

- attempt ID/index and approved transcript text;
- pack/version, subject, topic, variant, difficulty profile, prompt, and rubric;
- mode, challenge, register, support level, and complete time policy;
- coverage plus its scoring method/version.

No history is persisted or uploaded.

## 4. Refinement Delta

`src/scoring/refinementDelta.ts` returns a discriminated result:

- `available: true`: signed weighted-coverage delta, direction, newly covered concept IDs, and lost
  concept IDs;
- `available: false`: prior/current coverage unavailable, attempt identity mismatch, or scoring
  identity mismatch.

A numeric value exists only when every identity field above and `coverage.scoring` match. Missing
coverage never becomes a fabricated flat `0%`. Floating-point noise within `1e-9` is treated as
flat. The UI explains unavailable comparisons rather than hiding the reason.

## 5. Semantic meaning evidence

### Runtime and supply-chain boundary

- Model: `Xenova/all-MiniLM-L6-v2`, Apache-2.0, q8.
- Pinned public revision: `751bff37182d3f1213fa05d7196b954e230abad9` (verified against the
  Hugging Face repository on 2026-09-01; repository metadata last modified 2025-07-22).
- No remote script executes. The pinned model files are fetched only after opt-in and cached by
  Transformers.js; inference runs in a same-origin Web Worker with the vendored ORT WASM runtime.
- Semantic review requires only WebAssembly + Web Worker support. It remains available to typed
  learners without microphone, MediaRecorder, or Web Audio support.

The embedding client caps a job at 512 non-empty texts and 50,000 total characters, times out after
120 seconds, uses one in-flight job, drops stale attempt IDs, validates vector count/dimension and
finite values, and terminates on cancellation, timeout, malformed output, or low memory.

Whisper and MiniLM use separate worker instances but the same `transcribe.worker.ts` asset. Vite
therefore emits Transformers.js once instead of adding a second ~0.9 MB worker graph. Only public
rubric embeddings are cached in an eight-entry bounded insertion-order map; learner transcript vectors
are not cached.

### Evidence algorithm

1. Run v0.4 lexical coverage first.
2. Split approved text (already capped at 20,000 characters) by sentence/newline; split long or
   unpunctuated answers into overlapping 48-word windows and cap at 96 segments.
3. Embed each segment and each concept's deduplicated `[label, ...acceptedPhrases]` list.
4. Preserve every exact lexical hit.
5. For each lexical miss, retain the highest finite segment↔rubric cosine pair.
6. Show pairs at or above the experimental possible threshold (`0.35`) as “possibly present — not
   counted”, including both the learner wording and rubric wording.

The threshold set is versioned as `minilm-l6-v2-experimental-v1`. Its covered threshold is `1.01`,
deliberately above cosine's maximum: semantic evidence cannot affect numeric coverage until a later
educator-labelled calibration explicitly lowers and versions it.

A local pinned-model probe on 2026-09-01 found exact phrase-in-sentence similarities around
`0.66–0.69`, selected clear paraphrases around `0.17–0.51`, and selected unrelated pairs around
`0.00–0.12`. This engineering probe proves the original unverified `0.75` claim was unusable; it is
not educator calibration and is not represented as one.

## 6. UI contract

- Attempt one shows transcript, lexical coverage, one prescription, delivery, and an attempt trace.
- Attempt two+ shows Refinement Delta above coverage when comparable, or an explicit unavailable
  reason when not.
- Newly covered/lost labels are visible.
- Possible semantic evidence is separate from missed/touched lists and explicitly not counted.
- All model/content text renders as inert React text.
- “Try again on this topic” remains available; “Spin again” starts a new topic chain.

## 8. Release boundary

The 20-topic MPT pack remains a source-linked **unreviewed draft**. v0.5 is suitable for public
practice-beta testing, not a medically approved release. Qualified educator attestation of the
exact prompts, rubrics, accepted phrases, and semantic calibration set remains mandatory before
semantic evidence can alter numeric coverage or the beta can claim medical approval.
