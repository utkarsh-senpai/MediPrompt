## Learner contract

The v0.9 public path is:

```text
choose Recall Sprint or Deep Research
  -> choose one of three active subjects
  -> spin
  -> see one random topic
  -> use What? / So what? / Now what?
  -> complete a 60-second spoken answer
  -> review delivery or transcript
  -> retry or spin again
```

Deep Research provides a 10-minute preparation timer before the same 60-second speaking phase.
The timer cannot start until a topic has been drawn. The full-fingerprint shuffled bag draws every
eligible topic once before reshuffling and avoids an immediate repeat at a cycle boundary.

The Explain/Apply/Defend selector, Viva defense ladder, and private learning plan are not reachable
in v0.9. Their internal modules and historical tests remain for later deliberate reactivation; they
must not leak buttons, status text, persistence, or automatic save behavior into this release.

## Neuro catalog contract

`content/catalogs/neuro-physiotherapy-topics.json` is the editable Neuro source of truth. It stores:

- catalog identity, version, source-document label, and `expectedTopicCount`;
- ordered sections with a stable `sectionId` and display `titlePrefix`;
- stable topic IDs and labels;
- optional authored `prompt` and `concepts` fields for source-linked coverage.

The generator rejects blank or malformed identifiers, blank text, empty sections, duplicate section
IDs, duplicate topic IDs, duplicate rendered titles, and a mismatch between the actual and expected
topic counts. Each topic is rendered as `Section — Label`, including `Stroke — Hemiplegic gait`.

### Add or delete a topic

1. Add or remove one topic object in the relevant catalog section.
2. Adjust `expectedTopicCount` by the same amount.
3. Preserve a stable unique kebab-case `topicId`; do not renumber unrelated IDs.
4. Regenerate the candidate and review worksheet.
5. Run content validation and the complete test/build suite.

No React, session, randomization, or validator source code changes are required. Generated candidate
and worksheet files must never be hand-edited.

### Add content coverage

A label-only topic is intentionally scorable for delivery but not for medical content. The UI says
that source-grounded coverage is unavailable instead of assigning zero or fabricating a grade.

To enable existing lexical coverage for a topic, add these optional fields to its catalog object:

```json
{
  "topicId": "stable-topic-id",
  "label": "Concise topic label",
  "prompt": "Original, reviewed speaking prompt.",
  "concepts": [
    {
      "label": "One source-grounded expected idea",
      "acceptedPhrases": ["one acceptable phrase", "another acceptable phrase"],
      "sourceRefs": ["existing-source-id"]
    }
  ]
}
```

Every referenced source must exist in the candidate source register. Generation then creates both
Recall Sprint and Deep Research Guided variants and matching rubrics without generator-code changes.
Clinical answer criteria still require qualified human review before any approved medical release.

## Cost, tokens, and scaling

Catalog generation and random draws are deterministic local operations. Neither mode calls ChatGPT
or another hosted model, so adding or practicing these topics consumes zero API tokens. Optional
Whisper transcription and MiniLM evidence run in the browser after explicit learner activation.

The current generated pack is about 1.10 MB and is kept out of initial-entry JavaScript. Runtime
loading, content validation, service-worker caching, and PWA precaching share a 2 MiB ceiling. The
schema permits up to 1,000 topics in one subject, while global scan and file-size bounds still
protect against unbounded input. Before real content approaches 2 MiB, split runtime delivery into
one versioned core manifest plus lazy, independently validated subject shards; do not keep raising a
single-file limit indefinitely.

## Safety boundary

The 365 Neuro items are short educational speaking topics, not generated answers, patient-specific
advice, diagnoses, or treatment decisions. For that reason the repeated learner-facing attestation
banner is removed. The pack remains `MEDICAL`/`DRAFT` with no reviewer/date, the application footer
retains its educational disclaimer, and approval gates continue to fail closed.

Cardiorespiratory and Sports source-authored criteria remain unchanged. The generated active-subject
worksheet marks label-only Neuro topics as scaffolded and excludes them from attestation until
source-linked concepts are authored.
